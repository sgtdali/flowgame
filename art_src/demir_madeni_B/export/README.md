# Demir madeni node B - oyun ici deneme

- demir_madeni_sheet.png: seffaf RGBA sprite sheet.
- demir_madeni_sheet.json: kare konumlari ve sureleri.
- Dizilim: 4 sutun x 3 satir.
- Kare boyutu: 288 x 256 piksel.
- Kare sayisi: 12.
- Her kare: 100 ms (10 FPS).
- Dongu suresi: 1.2 saniye.
- Goruntu filtresi: nearest / en yakin komsu.

Bu ilk deneme gorselidir. DEMIR, 30/DK, duraklatma simgesi ve cikis
soketi resme dahildir; bunlar canli oyun verisi veya tiklanabilir UI degildir.
Oyun entegrasyonunda sayilar, butonlar ve gercek baglanti portlari ayri
UI olarak baglanmalidir. Orijinal ASE dosyasinda etiket ayri katmandadir.
